# Ejercicio_2_DDAM
Conversor de Unidades es una aplicación móvil diseñada para facilitar la transformación de medidas de longitud, 
como la conversión de metros a pies. Su interfaz está pensada para ser rápida y directa: el usuario simplemente 
ingresa la cantidad en el campo numérico, presiona el botón de conversión, y la aplicación procesa y muestra el
equivalente exacto al instante.
